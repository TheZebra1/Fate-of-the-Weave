## Process
- Costs **100 gp + 1 workweek** to find a seller.
	- Spending **extra time (1 workweek)** grants **+1 bonus** to the check (max +10).
	- Spending **+100 gp** grants **+1 bonus** to the check (max +10).
- Roll **Charisma (Persuasion) check** to determine item availability.

### Item Type Check

| Roll 1d4 | Items Acquired |
| -------- | -------------- |
| 1        | Arcana         |
| 2        | Armaments      |
| 3        | Immplements    |
| 4        | Relics         |
### Rarity Check
| Check Total | Items Available                 |
| ----------- | ------------------------------- |
| 1-8         | Roll **1d6** common             |
| 9-16        | Roll **1d4** uncommon           |
| 17-24       | Roll **1d4** rare               |
| 24-32       | Roll **1d4** very rare          |
| 33-39       | Roll **1** legendary            |
| Nat 20      | Upgrade roll to next tier       |
| 40 + N20    | All items are ***half-price***. |
## Magic Item Prices
| Rarity     | Price |
|-----------|----------------|
| **Common**     | (1d6 + 1) × 10 gp |
| **Uncommon**   | 1d6 × 100 gp |
| **Rare**       | 2d10 × 1,000 gp |
| **Very Rare**  | (1d4 + 1) × 10,000 gp |
| **Legendary**  | 2d6 × 25,000 gp |
- **Consumables (potions, scrolls, etc.) cost half.**
## Finding Specific Items
If a character seeks a **specific** item, they must pass the [[Buying Magical Items.Downtime#Rarity Check|rarity check]] for the desired item and then roll:

| Item Rarity | Required Check |
|------------|---------------|
| **Common** | 10+ |
| **Uncommon** | 15+ |
| **Rare** | 20+ |
| **Very Rare** | 25+ |
| **Legendary** | 30+ |
## Magic Item Purchase Complications
Each purchase has a **10% chance** of complications. Roll **d12**:

| d12  | Complication |
|----|-------------|
| 1  | Item is a **fake**, planted by an enemy. * |
| 2  | Item is **stolen** by the party's enemies. * |
| 3  | Item is **cursed** by a god. |
| 4  | **Original owner seeks to reclaim** it. * |
| 5  | Item is tied to a **dark prophecy**. |
| 6  | Seller is **murdered before sale**. |
| 7  | Seller is a **devil bargaining for a soul**. |
| 8  | Item is the **key to freeing an evil entity**. |
| 9  | **Bidding war** doubles the price. * |
| 10 | Item is a **sentient, enslaved entity**. |
| 11 | Item is **tied to a cult**. |
| 12 | **Rumors spread** that the item is evil. * |
* *Might involve a rival.*
