***To craft a nonmagical item, you need:***
- Tools
- Raw materials
- Time 
### [[armor-xphb|Armor]] & [[weapons-xphb|Weapons]]
| Item Category | Required Tool                                   |
| ------------- | ----------------------------------------------- |
| **Armor**     | Leatherworker’s, Smith’s, or Weaver’s Tools     |
| **Weapon**    | Leatherworker’s, Smith’s, or Woodcarver’s Tools |
|               |                                                 |
### Raw Materials
Half the purchase cost (**round down**) in materials
- *Ex. you need 750 GP of raw materials to make Plate Armor, which sells for 1,500 GP. The DM determines whether appropriate raw materials are available.*
### Crafting Time Calculation
- **Days required** = (*Item cost in GP*) ÷ *10* (**round up**).
	- ***Example:** A Heavy Crossbow (50 GP) takes 5 days.*
- **Non-Consecutive Days:** Crafting days don’t need to be consecutive.
- **Collaborative Crafting:**
  - **Divide** crafting time by the number of **contributors**.
	  - Typically, one assistant is allowed (DM discretion for more).
