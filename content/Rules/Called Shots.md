# ⚔️ Called Shots (House Rule)
You can trade accuracy & up-front damage for cinematic attacks that cause special effects.  
**Be warned: Enemies can use this too.**

## How It Works
- Declare a **Called Shot** before rolling.
- Attack with **–5 to hit**.
- On a hit:
	- Damage done to the target is halved.
	- Damage done is applied in full toward buying an effect.
- Each effect costs a % of the target’s **Max HP**.
- When the threshold is met, the effect happens.

## Effect Costs

| Effect                             | Cost (% of target’s Max HP)   |
| ---------------------------------- | ----------------------------- |
| Stagger (disadv. on next attack)   | 10%                           |
| Knock Prone / Off Balance          | 15%                           |
| Disarm (drop weapon/shield)        | 20%                           |
| Cripple Leg (speed halved)         | 25%                           |
| Blind I (one eye)                  | 30%                           |
| Silence (no speech/spells 1 turn)  | 35%                           |
| Disable Arm (no off hand/two-hand) | 40%                           |
| Ground Wing / Sever Tail           | 50%                           |
| Blind II (both eyes)               | 60% (cumulative with Blind I) |
| Dismember Limb (arm/leg lost)      | 70%                           |
| Decapitation / Instant Kill        | 100%                          |
## Notes
- Some effects may require **DM discretion** (e.g., which arm, how silence works).
